# ⚡ بوت التداول الفوري الذكي (Smart AI Spot Trading Bot)

بوت تداول فوري ذكي فائق التحفظ لإدارة رؤوس الأموال الصغيرة (يبدأ من 4 دولارات) مع حماية قصوى للأرباح ومنع الانتكاسات السعرية، يعمل بوضع المحاكاة الورقي المباشر (Paper Trading) مع إمكانية التبديل للتداول الحقيقي على منصتي **Bybit** و **Binance**.

---

## 🌟 الميزات الرئيسية

1. **إدارة رأس المال الصغير (4$):**
   - يدعم تقسيم الصفقات (مثلاً صفقتين بقيمة 2$ أو صفقة بـ 4$).
   - متوافق مع منصة Bybit التي تقبل صفقات فورية تبدأ من 1$، ومنصة Binance.

2. **استراتيجية أمان فائقة لتقليل الخسائر (Zero-Loss Defense):**
   - **تأكيد ثلاثي للمؤشرات:** لا يدخل البوت أي صفقة إلا عند توافق مؤشر القوة النسبية (RSI)، ارتداد نطاقات بولينجر (Bollinger Bands)، وتأكيد متوسطات الاتجاه (EMA 9, 21, 50).
   - **الوقف المتحرك الذكي (Trailing Stop):** بمجرد تحقيق ربح +0.8%، يرتفع وقف الخسارة تلقائياً لتأمين الأرباح ويتبع السعر الصاعد بمسافة 0.4% لحجز المكاسب ومنع تحول الصفقة إلى خسارة.
   - **أخذ الربح التلقائي (Take Profit):** عند بلوغ الهدف المحدد (افتراضياً +1.8%).

3. **مستشار الذكاء الاصطناعي باللغة العربية (AI Advisor Hub):**
   - يقدم تحليلاً حياً ومفهوماً لوضع السوق اللحظي.
   - يعرض أسباب الدخول أو الانتظار ونسبة الأمان لكل زوج.

4. **لوحة تحكم تفاعلية متطورة (Streamlit Dashboard):**
   - متابعة حية للرصيد، إجمالي الربح/الخسارة، ونسبة الصفقات الرابحة.
   - رسم بياني للشموع اليابانية والمؤشرات الفنية عبر Plotly.
   - جدول صفقات مفتوحة مع إمكانية الإغلاق اليدوي الفوري لأي صفقة.
   - زر إيقاف طارئ وتسييل (Emergency Kill Switch).
   - إمكانية إعادة تعيين الرصيد التجريبي (4$) بضغطة زر.

## 🚀 طريقة التشغيل السريع

### الطريقة الأولى: بنقرة واحدة (ويندوز)
فقط اضغط مرتين على ملف:
```
run.bat
```
سيقوم تلقائياً بتجهيز البيئة وفتح لوحة التحكم في متصفحك على: `http://localhost:8501`.

### الطريقة الثانية: عبر سطر الأوامر (Terminal)
```bash
# تشغيل الواجهة
.venv\Scripts\python -m streamlit run app.py
```

---

## 📁 هيكل المشروع

- `app.py`: واجهة التحكم التفاعلية ولوحة المتابعة.
- `trading_engine.py`: محرك التداول، إدارة المحفظة، مراقبة الوقف المتحرك، وقاعدة البيانات.
- `ai_advisor.py`: محرك استشارات الذكاء الاصطناعي وتوليد التوصيات والتحليلات باللغة العربية.
- `indicators.py`: حساب المؤشرات الفنية (RSI, EMA, Bollinger Bands, ATR).
- `config.py`: ملف الإعدادات وإدارة المخاطر.
- `trading_data.db`: قاعدة بيانات SQLite لحفظ الصفقات وسجل العمليات والرصيد تلقائياً.
- `run.bat`: مشغل التشغيل السريع لويندوز.
- `test_bot.py`: اختبارات شاملة للتأكد من سلامة النظام.

## 💡 التبديل إلى التداول الحقيقي (Live Trading)
عندما ترغب في الانتقال من الوضع التجريبي إلى التداول الحقيقي بأموالك:
1. افتح الشريط الجانبي في لوحة التحكم.
2. اختر **"تداول حقيقي (Live Trading)"**.
3. أدخل مفاتيح API الخاصة بك (API Key & API Secret) من حسابك في Bybit أو Binance مع تفعيل صلاحية Spot Trading فقط (لا تقم بتفعيل السحب).
